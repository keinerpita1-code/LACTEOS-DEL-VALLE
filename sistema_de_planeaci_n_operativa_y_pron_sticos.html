Lógica de Cálculo MPS & ATP:

• Inv. Final Proyectado = Inv. Inicial + MPS - Máx(Pronóstico, Pedidos Confirmados).
• MPS (Producción) = Se activa si Inv. Inicial < Máx(Pronóstico, Pedidos) para cubrir el Lote Fijo/L4L.
• ATP (Disponible para Promesa) = (Inv. Inicial + MPS) - Suma de Pedidos hasta el siguiente lote de producción.
